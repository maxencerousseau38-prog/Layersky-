Layersky API

Translation and pull-request service. Every /v1/* route requires a bearer token; there is nothing here to browse.

  • GET /health — liveness, unauthenticated
  • POST /v1/translate — bearer token required
  • POST /v1/open-pr — bearer token required

Source-derived context (file paths, component names, surrounding code) is sent to Anthropic, which is not hosted in the EU. This is a known, documented gap against the project's data-residency invariant.
